Download **only** from the official source - the GitHub Releases page (linked
from <https://ellekit.space/dopamine/>):

<https://github.com/opa334/Dopamine/releases>

- Grab the latest release (**3.0.9** or newer). **Do not use 3.0 - 3.0.6** - those
  have a kernel-panic bug; **use 3.0.7+**.
- Download **`Dopamine.ipa`** (for the free-Apple-Account installers on the next
  page). Only grab **`Dopamine.tipa`** if you already have TrollStore.

> **Which file?** `.ipa` = the normal package the free-Apple-Account tools
> (Sideloadly / AltStore / SideStore) install. `.tipa` = the same app packaged
> for **TrollStore** (permanent signing, no 7-day expiry) - only useful on
> TrollStore-capable devices (≈ iOS 14.0 - 16.6.1).

Next: **[Install Dopamine on the phone →](/device-access/ios/install/)** - pick one installer.
